# Biruk Keyboard App

A landscape-first Android arranger-keyboard project built from scratch for the Biruk Keyboard App repository.

## Current direction
- Horizontal performance layout inspired by pro arranger keyboards
- Full-width touch keyboard
- Offline synthetic audio engine
- Top control strip for voice, style, mixer, split, layer, sustain, transpose, and transport
- GitHub Actions build pipeline for debug APK output

## Notes
- This project uses an original interface and implementation.
- It does not include proprietary Yamaha software, samples, or assets.
- The first version focuses on the core performance screen and a working sound engine.

## Build
Use GitHub Actions to generate the debug APK artifact from the `main` branch.
