# Biruk Keyboard App

A landscape-first virtual arranger keyboard project inspired by the workflow of professional arranger keyboards.

## Project direction
- Landscape-only main performance screen
- Full touch keyboard
- Interactive performance controls
- Offline-first audio architecture
- Voice, style, mixer, effects, and registration systems
- GitHub Actions build pipeline

This project uses an original UI implementation and does not include proprietary Yamaha software, samples, or assets.
